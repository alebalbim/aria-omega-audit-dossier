### 🧠 Por que a "Trilha do Pensar" é Revolucionária
IAs tradicionais dizem *o que* decidiram. O ARIA OMEGA prova *como* decidiu. A cada ciclo, o sistema gera uma trilha cognitiva documentando:
- ✅ **Intenção Ex-Ante:** O que o sistema planejou antes de agir.
- ✅ **Fontes de Dados Consultadas:** GitHub, ArXiv, BACEN SGS (com tempos reais de execução em ms).
- ✅ **3 Caminhos Ativamente Rejeitados:** Documentação explícita do motivo pelo qual alternativas (ex: Redes Neurais Profundas) foram rejeitadas em favor de métodos explicáveis.
- ✅ **Métricas Reais de Treino:** Scores reais de MSE, provando que o modelo foi avaliado, não apenas implantado.
- ✅ **Autoauditoria Ex-Post:** Verificação automática da Hash-Chain e assinaturas TSA antes de finalizar o ciclo.

### 🔍 Como Verificar a Integridade
Qualquer auditor pode verificar independentemente as afirmações do sistema:
1. **Baixe** o artefato `.json`.
2. **Recalcule** os hashes SHA-256 de cada registro.
3. **Verifique** a cadeia de hashes (o `hash_versao_anterior` de cada registro deve corresponder ao `hash_atual` do registro anterior).
4. **Valide** a assinatura TSA RSA-PSS/SHA-256 usando a chave pública incorporada.
